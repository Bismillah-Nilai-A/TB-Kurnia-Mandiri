# Dokumentasi Wireframe, Interactive Prototype & Panduan Gaya Figma TB Kurnia Mandiri

Folder ini (`dokumentasi-wireframe/`) berisi catatan pembuatan dan riwayat revisi khusus untuk **Low-Fidelity Grayscale Wireframe, Interactive Prototype, dan Halaman Panduan Gaya Figma** yang berada di folder [`../wireframe/`](../wireframe/README.md).

Folder ini dipisahkan dari [`../dokumentasi-sistem/`](../dokumentasi-sistem/README.md) agar dokumentasi proyek aplikasi utama tidak tercampur dengan dokumentasi tahap perancangan wireframe.

## Daftar Dokumen Wireframe

1. [**01 - Pembuatan Awal Wireframe & Interactive Prototype**](./01-wireframe-dan-interactive-prototype.md)
   - Analisis Use Case, Activity Diagram To-Be, Class Diagram, dan ERD menjadi 21 tampilan wireframe interaktif untuk 3 peran (`Pemilik`, `Kasir`, `Pengirim`) menggunakan data dummy lokal di frontend.
2. [**02 - Revisi Desain Low-Fidelity Wireframe Mengikuti Aplikasi Utama**](./02-revisi-desain-wireframe-low-fidelity.md)
   - Penyederhanaan tampilan grayscale agar bersih dari elemen dekoratif berlebih, penggantian simbol teks dengan ikon SVG, serta penerapan `CustomSelect` dan `ResponsiveTabs`.
3. [**03 - Perbaikan Sidebar, Header Setting, Wireframe Login & Responsivitas Form**](./03-perbaikan-header-login-dan-responsif-wireframe.md)
   - Penghapusan tombol `X` dan info akun di sidebar, penambahan tombol pengaturan tampilan & dropdown profil di header, penyesuaian halaman login split-screen dengan kotak gambar garis silang, serta perbaikan grid form 2 kolom.
4. [**04 - Penyelarasan Katalog & Keranjang POS, TablePagination, dan Responsif Desktop**](./04-penyelarasan-pos-pagination-dan-responsif-desktop.md)
   - Penyelarasan tinggi kartu katalog dan keranjang di halaman POS, penambahan `TablePagination` interaktif, serta perapian tata letak desktop.
5. [**05 - Perbaikan Tata Letak Tabel Lebar Penuh & Konsistensi Paginasi**](./05-perbaikan-layout-tabel-dan-konsistensi-paginasi.md)
   - Penghapusan paginasi pada katalog kasir POS, pelebaran tabel di halaman Dashboard dan Stok Minimum & Restok menjadi 100% lebar penuh, penyeragaman paginasi di halaman Penukaran Barang, serta penghapusan item `Pengaturan Akun` pada dropdown profil header.
6. [**06 - Pembuatan Halaman Panduan Gaya (`panduan-gaya.html`) & Katalog Dropdown Terbuka untuk Figma**](./06-panduan-gaya-komponen-dan-aset-figma.md)
   - Pembuatan halaman mandiri `wireframe/panduan-gaya.html` yang menampilkan palet warna, ukuran teks `Plus Jakarta Sans`, lencana status, tombol, dan seluruh komponen dropdown dalam kondisi terbuka statis agar terbaca penuh oleh ekstensi browser-ke-Figma.
7. [**07 - Penyederhanaan Teks Halaman Panduan Gaya Sesuai Aturan Anti-Slop**](./07-penyederhanaan-teks-panduan-gaya-anti-slop.md)
   - Pemangkasan paragraf penjelasan berlebih, nomor teknis, dan lencana kategori pada `wireframe/panduan-gaya.html` agar bersih seperti contoh panduan gaya referensi.
